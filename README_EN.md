# COMING SOON

Intended usage:

```shellsuite <module> <action> -arg ```

Where ```shellsuite``` refers to ShellSuite, ```<module>``` refers to ShellShock or ShellBlock, ```<action>``` refers to what you want to do inside the module (in the case of ShellShock create or manage) and ```-arg``` are whatever arguments you want to include (in the case of webshell creation: type, authentication, encryption, etc).
